# pump_task

| File | Use |
|---|---|
| pump_task_inputs.zip | Six prepared inputs. Make a folder named pump_study, unzip these six files into it, and open the folder in VS Code. Nothing else goes in the folder. |
| Pump_Selection_Timed_Script.docx | Timed, word by word script in the same format as the droplet script. Read it from another device, never on the recorded screen. |
| Deliverables_REFERENCE.zip | Shows the correct Deliverables.zip layout (13 files, names with spaces) and the expected outputs. Use it to check your own results. Do not submit it. |

The video must show you creating the artifacts and final outputs. Build your own Deliverables.zip after recording from the files you made, using the names in the reference zip.

Provenance: the inputs were written and tested by Claude, not Gemini. Studio only accepts Gemini for AI generated inputs, so label them truthfully and ask Loki if unsure.

Typed on camera: 861 characters (trim lists in the script bring it to 773 or 676). No less-than or greater-than keys are needed.

Tested here: the six inputs unzipped into a clean folder, the typed lines placed in the starter notebook, and the notebook run end to end with no errors. Result: Pump B recommended (119.6 m3/h, 27.1 m head, 2.01 m NPSH margin, 60,247 USD over five years). Pump A fails NPSH (margin 0.41 m). Pump C costs 87,504 USD.

Not tested here: the VS Code, PowerPoint and Word menus and dialogs on a Mac. Do the dry run described in the script and fix any wording that differs.
